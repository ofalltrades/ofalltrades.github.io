# Jake Johnson

Personal portfolio and résumé site for Jake Johnson, a senior full-stack engineer. It is intentionally a small static site: no framework, package manager, build step, or JavaScript is required.

[jakejohnson.dev](https://www.jakejohnson.dev/)

## Structure

- `index.html` contains the page content.
- `style.css` contains the responsive styling.
- `images/` contains the case-study screenshots.
- `profile-pic.jpg` and `Phillip_Jake_Johnson_Resume_2026.pdf` are the downloadable portfolio assets.
- `CNAME` configures the custom domain for GitHub Pages.

## Use it as a starting point

Clone or fork the repository, replace the personal content and assets, and open `index.html` in a browser. Since it is plain HTML and CSS, it can be hosted by GitHub Pages or any static-file host without a build process.
